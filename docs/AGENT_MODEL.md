## 1. 접수 서류 목록 검증

대행 에이전시가 요청한 서류(원문):

1. **의뢰 업체**
   - 대표자 명함, 담당자 명함
   - 영문 사업자등록증
   - 영문 공장등록증
2. **의뢰 품목 수**, 의뢰 품목 **제품소개서**
3. 의뢰 품목별 **전성분 자료** — 영문 엑셀 파일

### 판정: ✅ MoCRA 대행 접수용으로 타당하고 일반적인 목록

단, **FDA에 직접 제출되는 서류**와 **에이전시가 내부적으로 수집하는 서류**를
구분해서 이해할 필요가 있다.

| 요청 서류 | FDA 직접 요구? | 실제 용도 (MoCRA 매핑) |
|-----------|:---:|------|
| 대표자/담당자 명함 | ❌ | 책임자(RP)·연락처 확인용 (에이전시 내부) |
| 영문 사업자등록증 | ❌ | 회사·RP 신원/주소 확인용 (에이전시 내부) |
| 영문 공장등록증 | ❌(서류 자체는 아님) | **시설 등록(Form 5066)** 의 시설명·주소 근거 |
| 제품 수 / 제품소개서 | ❌(서류 자체는 아님) | **제품 리스팅(Form 5067)** 품목·카테고리 판단 |
| 품목별 전성분(영문 엑셀) | ✅(성분 목록 필요) | **제품 리스팅**의 성분 목록(INCI) |

> FDA가 실제로 요구하는 데이터(공식):
> - **시설 등록**: 시설명·주소·이메일·전화, **FEI**, 브랜드명, 제품 카테고리
> - **제품 리스팅**: 시설 FEI, 책임자(RP) 이름·연락처, 제품 카테고리, **성분 목록**
> - **해외 기업**: **US Agent** 지정 필수
> 제출 채널은 **Cosmetics Direct**(전자 포털) 또는 ESG NextGen. (출처: FDA)

### 목록에서 눈여겨볼 점 / 보완 권장

- **FEI 번호**: 공장등록증만으로는 안 되고, FDA에서 FEI를 발급받아야 함
  (보통 에이전시가 대행). 시설 등록의 핵심 키.
- **US Agent 지정**: 해외(한국) 기업은 필수. 보통 **에이전시가 US Agent 역할**을
  겸함 → 그래서 별도 서류로 요구 안 하는 것.
- **책임자(RP) 지정**: 라벨 표기 기업이 RP. 명함/사업자등록증으로 신원 확인.
- (선택) 라벨 이미지, 제품 표기(claim) 자료는 안전성·표시 검토 시 추가로 요청될 수 있음.

**결론**: 에이전시 목록은 정상. "명함·사업자·공장등록증"은 FDA 제출물이 아니라
**에이전시가 신원·시설·연락처를 확정하기 위한 수집 서류**라는 점만 이해하면 됨.

## 2. 에이전트 대행 모델 정의

```
고객(한국 화장품사)                에이전시/US Agent              FDA
  │  서류·데이터 업로드   ──▶  │  검토·FEI 발급·SPL 준비  ──▶ │ Cosmetics Direct
  │  (플랫폼)                 │  대리 제출                    │  / ESG
  │  ◀── 진행상황·마감 알림 ── │  ◀── ACK/등록번호 수신 ────── │
```

- **플랫폼 역할**: 고객이 서류·제품·전성분을 올리는 **접수/준비 도구**.
  실제 FDA 제출은 **에이전시(US Agent)** 가 수행 → API 직접 연동(FR-08) **불필요/보류**.
- 이는 기획서 §11.1 "도구 제공 + 고객 최종 제출(도구형)" MVP와 일치.

## 3. 현재 플랫폼 ↔ 대행 모델 매핑

이미 구현된 기능이 대행 모델을 대부분 커버한다.

| 대행 접수 항목 | 현재 기능 | 상태 |
|---------------|-----------|:---:|
| 회사·대표/담당자·사업자등록증 | 회원가입/조직 + 온보딩(RP) + 문서보관함 | ✅ |
| US Agent | 온보딩 US Agent (partner/direct) | ✅ |
| 공장등록증 → 시설 | 시설 등록(FR-04), FEI 필드 | ✅ |
| 제품 수·제품소개서 | 제품 등록/일괄(FR-05/06), 문서보관함 | ✅ |
| 품목별 전성분(영문) | 성분 + INCI 매핑(FR-07) | ✅ |
| 서류 보관(명함·인증서·소개서) | 문서 보관함(FR-11) type 분류 | ✅(부분) |
| 마감·갱신 관리 | 컴플라이언스 캘린더(FR-09) | ✅ |
| **FDA 직접 제출(ESG API)** | FR-08 | ⏸ 보류(대행이 수행) |

### 갭 / 다음 후보

1. ✅ **접수 서류 체크리스트** (구현됨): 문서 type 확장(`biz_registration`,
   `factory_registration`, `business_card`, `product_brief`, `ingredient_sheet`)
   + `GET /workspaces/{id}/intake-checklist` + 프론트 `/intake` 화면.
2. ✅ **전성분 영문 엑셀 업로드 → INCI 매핑** (구현됨):
   `POST /products/{id}/ingredients/upload` (.xlsx 파싱 → INCI 자동 매핑),
   제품 화면에 업로드 버튼.
3. ⏳ **에이전시 제출 상태 수동 기록** (미구현): ESG 자동화 대신, 에이전시가
   접수/완료 상태를 수동 업데이트(제출ID·등록번호 입력)하는 필드. (submission 모델 재사용)
